# Awesome Goblin Lang

A curated directory of tools, tutorials, and infrastructure for the **Goblin Programming Language** ecosystem.

## 🌐 Core Domains
* [Official Website](https://goblinlang.org) — Core technical specifications, syntax manuals, and compiler binaries.
* [Tutorials Hub](https://goblintuts.com) — Step-by-step code recipes, language guides, and walkthroughs.

## 📦 Package Registry
* **GLAM** — *In Active Development* — The package management system for Goblin (short for "glamor", or unofficially "goblin libraries and modules"), functioning like a Ruby gem to distribute third-party modules.

## 💬 Community Channels
* [r/GoblinLang Subreddit](https://reddit.com) — The official community hub for compiler updates, feature discussions, and code showcases.

## 🛠 Native Language Tools
Tools built directly using the Goblin language:
* [Sheriff](https://goblinlang.org) — The static site generation tool written in Goblin, used to compile and build the language documentation.
* [Sheriff Cloud](https://sheriffcloud.com) — The hosted version of Sheriff featuring an integrated WYSIWYG editor and automated deployment infrastructure.
